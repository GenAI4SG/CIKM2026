# GenAI4SG Workshop Website

Static GitHub Pages website for **GenAI4SG: Generative AI for Social Good and Vulnerable Populations**, held with CIKM 2026 in Rome, Italy.

## Structure

- `index.html` - main website page
- `assets/css/main.css` - custom styles
- `assets/js/main.js` - small site script
- `assets/img/` - Rome images, organizer photos, and logos

## Local Preview

From this folder, run:

```bash
python3 -m http.server 8000
```

Then open `http://127.0.0.1:8000/`.

## GitHub Pages

Publish this `website/` folder as the GitHub Pages site root, or copy its contents to the root of the GitHub Pages branch.
